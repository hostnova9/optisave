# OptiSave v1.20
- Paystack KYC success is now committed atomically with the success notification.
- Existing accounts with a prior `Identity verified` success notification are reconciled to verified on profile load.
- Verified provider state remains authoritative over stale pending UI values.
- Dashboard sidebar now uses a circular initials card, live device date/time, user greeting and previous login.
- Sidebar identity has cached-session and profile fallbacks so it does not remain as `--` when `/auth/me` is delayed.
