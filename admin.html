1. Connection & Business Profile

READ ONLY

Authenticates with your sandbox Secret Key and reads the Fincra business profile. If a Business ID is returned, OptiSave detects it automatically for this server session.

2. Nigerian Banks

READ ONLY

Loads Fincra's sandbox list of NGN destination banks so we can confirm bank codes before account verification and payouts.

3. Temporary NGN Virtual Account

SANDBOX

Uses Fincra's documented Pay-with-Transfer sandbox endpoint to create a temporary NGN collection account.

4. Permanent Virtual Account Request

KYC PAYLOAD

Calls /profile/virtual-accounts/requests. Paste only sandbox/test customer data that matches Fincra's current documentation. Never put real customer KYC into this developer lab unless Fincra explicitly requires it for your approved test account.

5. Verify Nigerian Bank Account

READ ONLY

Resolve the beneficiary name before a payout using Fincra's account verification endpoint.

6. Local NGN Payout

SANDBOX WRITE

This lab only permits NGN → NGN bank-account payouts and applies a server-side sandbox amount cap.
