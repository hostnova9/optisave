About OptiSave

Product information and policies

Save with structure.

OptiSave is being built around disciplined saving through Lock Only, Lock & Allocation and Daily Savings. This package is a development build and is not yet a live financial service.

Lock Only

Keep funds locked toward a chosen maturity date with controlled plan rules.

Lock & Allocation

Lock funds while scheduling part of the plan for controlled periodic availability.

Daily Savings

Build a saving habit with scheduled daily contributions toward a target.

Security & Verification

Profile, bank, KYC and security interfaces are prepared for secure backend integrations.
